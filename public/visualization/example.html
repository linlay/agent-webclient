可复制到 Agent 提示词的约定 
生成供 WebClient 预览的 HTML 时，使用以下内置资源，不使用外部 CDN：
ECharts：<script src="/assets/visualization/echarts.min.js"></script>
Mermaid：<script src="/assets/visualization/mermaid.min.js"></script>
可选页面样式：<link rel="stylesheet" href="/assets/visualization/preview.css">
只加载页面实际使用的库，使用普通 script 标签，分别通过 echarts 和 mermaid 全局对象调用。
ECharts 容器必须有明确高度；Mermaid 使用 securityLevel: "strict"。
先创建容器，再执行初始化；布局变化时调用 ECharts resize。
这些资源地址用于 WebClient 预览，下载后直接双击 HTML 不保证可用。
