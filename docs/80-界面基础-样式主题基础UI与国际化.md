# 样式主题基础UI与国际化

## 当前状态
全局样式入口仍为 `src/shared/styles/globals.css`，但它只加载 Tailwind theme/utilities 与 `globals/base.css` 中的 token、reset、基础排版、可访问性和真正通用 UI。Layout、Sidebar、Composer、Timeline、Tools、Voice、Project、Agent、Memory、Archive、Command 等样式已经迁入 app/feature 自有 CSS Modules。

## 核心职责
- 保持唯一全局基础入口，领域组件在自己的加载边界引入 `*.module.css`。
- 提供主题模式读取、持久化和 document attribute 应用。
- 维护 UiButton、UiInput、UiTag、MaterialIcon、ConversationMarkdown、MarkdownContent 等基础组件。
- 在 `globals/base.css` 维护跨页面复用的图标、点击热区、控件高度和表单间距变量；Automations、Agents、Skills Center、MCP、Registries 与 Archived Chats 逐步统一消费这些变量。
- 提供 zh-CN/en-US 文案和硬编码中文检查约束。

## 核心流程
`src/app/index.tsx` 只导入主应用 `globals.css`。App layout 和各 feature 组件自行导入领域 CSS Modules；仍需匹配既有语义 class 或 Ant Design portal DOM 时，模块使用逐选择器 `:global(...)`，portal 组件优先通过 `rootClassName`、`popupClassName` 或 `classNames` 注入作用域。应用启动时解析 URL、localStorage 或宿主传入的主题/语言配置。组件通过 `useI18n` 或 `t` 获取文案。`ConversationMarkdown` 是不依赖 AppContext、鉴权、Desktop Bridge 和具体代码 UI 的消息正文渲染核心，统一负责 GFM、KaTeX 与安全 HTML 配置，并要求入口显式注入代码渲染器；主对话的 `MarkdownContent` 再注入完整代码渲染器、鉴权资源、Workspace 链接和 Desktop 操作。匿名分享页不再重建 transcript 或复用 Markdown 组件，只负责受限 Blob iframe 宿主。

静态 HTML 导出使用独立 CSS Modules、原生 `details/summary`、严格 Snapshot V1 parser 和固定语言集合的同步代码高亮，避免 Ant Design、Context、Router 与业务网络进入文件。模板不再内联 CSS 或可执行 JS：React、ReactDOM、KaTeX 与导出样式进入同一主 JS/CSS，ECharts/Mermaid 仅在命中对应代码块时从主 runtime 所在的内容寻址资产目录各加载一次，失败回退源码。Highlight 与 Mermaid 生成 markup 统一经过唯一 DOMPurify 边界；每轮内容使用 `content-visibility` 优化长对话，打印媒体规则展开思考，明暗色跟随 `prefers-color-scheme`。

基础尺寸变量以视觉尺寸和点击热区分开命名：`--ui-icon-size-sm: 16px` 对应常用图标，`--ui-icon-hit-size-sm: 24px` 对应紧凑图标按钮热区；`--ui-control-height-mini/sm/md` 分别为 24/32/36px。表单使用 `--ui-form-gap`、`--ui-section-gap` 和 `--ui-section-padding-start`，避免各管理页面重复写死尺寸。

## 边界与非目标
- 领域选择器不得进入 `shared/styles/globals`；`npm run check:boundaries` 会扫描 `agent-*`、`memory-*`、`automation-*`、`timeline-*` 等前缀。
- CSS Module 中引用外部全局 keyframe 会被 loader 改名；应在模块内定义对应 keyframe，或由拥有者通过模块 class 建立动画关系。
- 业务组件不应直接复制基础按钮/输入样式。
- 新增用户可见中文时，需要同步 i18n 词条或加入明确允许清单。
- 静态导出组件树不得依赖主应用状态、鉴权、Desktop Bridge 或业务网络；富文本只经过集中式 `SanitizedMarkup`/DOMPurify 边界。
- 导出入口不得包含业务网络、鉴权或 Desktop Bridge；生产构建后使用 `npm run check:conversation-export` 校验模板无内联样式/可执行脚本、唯一 Snapshot 占位符、内容寻址资产、CSP、SRI、固定依赖版本和包体预算。
