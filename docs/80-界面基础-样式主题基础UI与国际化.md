# 样式主题基础UI与国际化

## 当前状态
全局样式入口仍为 `src/shared/styles/globals.css`，但它只加载 Tailwind theme/utilities 与 `appearance/tokens.css` 的语义 token 与 `globals/base.css` 中的 reset、基础排版、可访问性和真正通用 UI。Layout、Sidebar、Composer、Timeline、Tools、Voice、Project、Agent、Memory、Archive、Command 等样式已经迁入 app/feature 自有 CSS Modules。

## 核心职责
- 保持唯一全局基础入口，领域组件在自己的加载边界引入 `*.module.css`。
- 提供主题模式读取、持久化和 document attribute 应用。
- 维护 UiButton、UiInput、UiTag、MaterialIcon、ConversationMarkdown、MarkdownContent 等基础组件。
- 在 `appearance/tokens.css` 维护跨页面复用的图标、点击热区、控件高度和表单间距变量；Automations、Agents、Skills Center、MCP、Registries 与 Archived Chats 逐步统一消费这些变量。
- 提供 zh-CN/en-US 文案和硬编码中文检查约束。

## 核心流程
`src/app/index.tsx` 只导入主应用 `globals.css`。App layout 和各 feature 组件自行导入领域 CSS Modules；仍需匹配既有语义 class 或 Ant Design portal DOM 时，模块使用逐选择器 `:global(...)`，portal 组件优先通过 `rootClassName`、`popupClassName` 或 `classNames` 注入作用域。应用启动时解析 URL、localStorage 或宿主传入的主题/语言配置。组件通过 `useI18n` 或 `t` 获取文案。`ConversationMarkdown` 是不依赖 AppContext、鉴权、Desktop Bridge 和具体代码 UI 的消息正文渲染核心，统一负责 GFM、KaTeX 与安全 HTML 配置，并要求入口显式注入代码渲染器；主对话的 `MarkdownContent` 再注入完整代码渲染器、鉴权资源、Workspace 链接和 Desktop 操作。在线分享与本地 HTML 导出通过 `ConversationExportDocument → ConversationPreview → ConversationStage` 展示严格解析后的 Snapshot V1，并注入 `ConversationMarkdown` 与 `ConversationMarkdownCode`；在线分享的已发布 HTML 附件在受限 iframe 中预览。

静态 HTML 导出复用统一时间线与代码块组件，使用独立入口和 CSS Modules；不挂载主应用 AppState、路由、鉴权或 Desktop Bridge。模板通过内容 Hash 资源和 SRI 加载独立 JS/CSS。Markdown 正文由 `ConversationMarkdown` 开启 `escapeRawHtml` 并配置 DOMPurify 禁止标签；代码高亮由 highlight.js 转义源文本，Mermaid 使用 strict 安全配置。这些渲染入口分别维护其安全配置。在线分享附件通过 `/share/{shareId}/attachments/{id}/preview` 或 `download` 访问，HTML 预览 iframe 使用空 sandbox；本地导出不开放该在线附件入口。

主对话时间线显式开启 `MarkdownContent.htmlPreview`，其 `html` 代码块在 fence 闭合后支持内联显示；BTW、Plan、来源详情、Automation 抽屉和 Markdown 文档查看器默认保留源码：以 HTML doctype 或 `<html>` 开头的完整文档默认显示，片段需点击“显示内容”。接收中使用 BusyInk 和“HTML 数据接收中…”占位，源码默认折叠，用户可主动展开；ContentBlock 传入真实接收状态，Run 结束或中断后未闭合块回退为源码。加载信号使用 XMarkdown 的 `streamStatus=done`，已验证标准反引号与波浪线 fence；三反引号配四反引号关闭等解析器仍报告 loading 的组合保守保留源码。iframe 使用 `sandbox="allow-scripts"`，宿主移除原文 base/HTTP-equiv meta 并在首部注入 CSP。允许内联脚本运行和指定的内置图表库，限制连接、外部图片、嵌套 frame、worker 与表单出口；CSP 不按脚本用途判断安全。iframe 不接收 Chat、鉴权或宿主数据。

HTML 内容没有额外标题栏、边框或停止按钮，随测得内容高度撑开，不设最大高度或 iframe 内部纵向滚动；源码沿用所有代码块共用的 400px 上限与滚动。VH 单位和文档根节点的百分比高度在 iframe 内按加载时的 Chat 视口解析，避免 iframe 增高导致递归增长，不修改保存的原文。初次加载处理样式，后续只处理变更的行内样式，在样式表新增、加载或 CSSOM 修改时重新处理样式表；图表的 SVG 属性动画只触发合并测高。只在实际视口内加载，全局最多同时保留两个 iframe；排队项可点击“显示内容”切换当前显示项。仅取得显示名额后解析和注入文档；不支持 HTTP origin 的环境降级为源码提示。按内容指纹及宽度缓存高度，并记住片段的手动显示选择，虚拟列表卸载后恢复占位。退出视口会卸载，返回后脚本重新执行，交互状态不持久化。尺寸消息校验 iframe source、实例 token 和有限正数；普通链接跳转被取消，自我导航会关闭显示并记录阻止状态。公开分享和本地 HTML 导出显式关闭代码块内联 HTML，保留源码。

Mermaid 渲染区取消纵向高度上限，保留横向缩放和移动；ECharts 使用 SVG 画布，没有外层高度上限，支持 JSON 顶层可选数字 `height` 指定画布高度，也从像素 grid 的 top/height/bottom 推导所需高度，未指定时使用 320px 默认绘图尺寸。ECharts 顶层 height 是 WebClient 展示约定，其他 option 按原契约读取。

`/assets/visualization/echarts.min.js`（6.0.0）、`mermaid.min.js`（11.16.0）与可选 `preview.css` 随 WebClient 开发和生产构建提供，只在 HTML 引用时加载；两库无需独立 CSS。浏览器单文件副本额外增加约 4.7 MB（未压缩）Program Bundle 体积。HTML 预览只将这些已知路径解析到当前 WebClient origin，保留原文是否含 doctype，不修改保存的源码；独立文件与其他站点不能假定这些路径可用。可使用 `qa/webpack.markdown-html.cjs` 查看完整文档与片段的预览。 本地 Electron 42.11.4 / Chromium 148 的独立验证窗口已验证无标题栏、长内容完整高度、接收与中断状态、虚拟卸载恢复及排队切换。提供可缓存的 HTTP 响应后连续重建三次 iframe，两份图表库累计各请求一次；这不共享各 iframe 的 JS 解析执行环境，也不替代完整 Desktop 发布后的验收。

基础尺寸变量以视觉尺寸和点击热区分开命名：`--ui-icon-size-sm: 16px` 对应常用图标，`--ui-icon-hit-size-sm: 24px` 对应紧凑图标按钮热区；`--ui-control-height-mini/sm/md` 分别为 24/32/36px。表单使用 `--ui-form-gap`、`--ui-section-gap` 和 `--ui-section-padding-start`，避免各管理页面重复写死尺寸。

## 边界与非目标
- 领域选择器不得进入 `shared/styles/globals`；`npm run check:boundaries` 会扫描 `agent-*`、`memory-*`、`automation-*`、`timeline-*` 等前缀。
- CSS Module 中引用外部全局 keyframe 会被 loader 改名；应在模块内定义对应 keyframe，或由拥有者通过模块 class 建立动画关系。
- 业务组件不应直接复制基础按钮/输入样式。
- 新增用户可见中文时，需要同步 i18n 词条或加入明确允许清单。
- 静态导出不得依赖主应用状态、鉴权或 Desktop Bridge；Markdown、代码高亮和图表分别遵守上述渲染安全边界，不能把原始 HTML 直接插入正文。
- 导出入口不得包含业务网络、鉴权或 Desktop Bridge；生产构建后使用 `npm run check:conversation-export` 校验模板无内联样式/可执行脚本、唯一 Snapshot 占位符、内容寻址资产、CSP、SRI、固定依赖版本和包体预算。

## 外观统一入口

外观由 `features/appearance` 集中管理，默认 CSS token 是 Ant Design 的唯一颜色来源。明暗/皮肤/整页背景归属分离；HTML 首屏与 React 共用同一主题 resolver，宿主临时值不再由 AppState effect 写入 localStorage。Standalone 设置增加跟随系统、薄雾、图片和 Desktop v1 ZIP。详见[皮肤与背景协作](82-界面基础-皮肤与背景协作.md)。

### 局部样式回归入口

`npm run preview:appearance -- --env presentation` 启动无需后端的样式预览，覆盖明暗切换、窄容器、HITL 选中态、模型菜单、Composer 弹层和设置滚动容器。完整业务流程仍需后端联调。

Presentation 样式按所属 feature 使用 CSS Modules；组件通过 `bindCssModuleClasses` 同时保留语义类名与局部类名。Portal 在实际弹层根节点绑定局部类名，第三方子节点通过局部根下的 `:global(...)` 适配。边界检查禁止这些模块出现无局部锚点的顶层选择器。


## 工具展示语言与共享连接

工具名称由 Platform 按连接语言解析。Desktop 在连接建立和重连时同步当前全局语言，切换设置时通过 /api/locale 更新所有已连接通道，后续请求与实时事件使用新语言。WebClient 不向业务 payload 注入 locale，也不因语言切换自动重建 Run 订阅。HTTP 沿用 X-Locale。


## 过程展示与 Agent 配置

过程展示默认由 Platform 统一解析：Agent 的 `interactionConfig.defaultDetail` 覆盖 `agent-settings.yml` 对应 mode 的 `interaction-config.default-detail`，最终兜底 summary。WebClient 不维护 mode 默认表，也不再读取旧的 `agent-webclient.eventDetailLevel.v1` 全局偏好；设置面板移除全局精简/详细开关。Agent 管理表单提供继承模式配置、精简、详细，只有显式覆盖写入源码，恢复继承删除 defaultDetail 字段并保留其他交互覆盖。

普通 query/attach/chat 不发送 detail，BTW HTTP 同样省略。历史 `/api/chat.display` 提供 `defaultDetail/effectiveDetail`，无需等待当前 Agent hydration；流式 `run.start.display` 更新本 Chat 的展示配置，Chat 列表刷新保留已加载的 display。新会话在元数据到达前读取所选 Agent 的解析结果，字段缺失兜底精简。切换会话不使用其他 Agent 或旧全局偏好覆盖历史 owner 的配置。

独立 WebClient 的时间线与 BTW 根据 effectiveDetail 渲染，保留少数显式请求覆盖场景；Desktop broker 上游仍固定 full，时间线与 BTW 根据 defaultDetail 渲染，避免把传输 full 误当作默认详细；独立回放面的 seq 连续性检查根据 effectiveDetail 判断过滤造成的跳号。显式请求 detail 保留为调试/中间层下发选项，不写 Agent 或原始 query。


### 智能体头像的空闲与鼠标行为

New Chat 与导航栏的六种内置 `AgentIcon` 共用 `agentPointerRuntime`。New Chat 按 `data-agent-pointer-surface` 在主界面体验区响应，导航按 `data-agent-identity` 只响应所在行；鼠标停止约 1.5 秒后，眼神回正，自动恢复空闲。空闲在轻快转身、左顾右盼、待命打盹、伸个懒腰四组动作中随机选择，每组之间安静停留约 8–16 秒，避免连续重复；打盹仅在至少 60 秒无鼠标／触摸互动后进入候选。自然眨眼包含在动作中。

所有可见头像共享一套 document 监听器、活动期 RAF 和空闲截止时间计时器。进入鼠标跟随会取消空闲轨道；停止跟随后重新计算空闲间隔。不可见、页面隐藏、减少动态效果与卸载均暂停或取消相应调度，恢复时不补播。显式 `interactive={false}`、导出容器的 `data-agent-pointer-disabled` 和外部图片保持静态。

`agentMotion` 只定义八组有限 WAAPI 轨道与随机选取规则，头像的四组空闲动作和 Main Chat `run.activity` 的四组工作动作分别调度。运行态图标不响应鼠标。两者共用默认轮廓与五官，保持原 `viewBox="20 35 160 145"` 和图标占位；轮廓较宽的角色限制身体幅度，眼神与睁眼反应继续保留。转身背对时隐藏五官，灵光一现使用先眯眼、突然睁大眼睛的节奏。
