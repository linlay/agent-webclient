# 样式主题基础UI与国际化

## 当前状态
全局样式入口为 `src/shared/styles/globals.css`，再按 layout、timeline、composer、tools、voice、responsive 等拆分导入。主题工具在 `theme.ts`，基础 UI 组件在 `src/shared/ui/`，国际化运行时在 `src/shared/i18n/`。

## 核心职责
- 统一全局 CSS 入口，避免在 app 入口散落多个全局样式文件。
- 提供主题模式读取、持久化和 document attribute 应用。
- 维护 UiButton、UiInput、UiTag、MaterialIcon、ConversationMarkdown、MarkdownContent 等基础组件。
- 提供 zh-CN/en-US 文案和硬编码中文检查约束。

## 核心流程
`src/app/index.tsx` 导入主应用 `globals.css`，主应用与分享入口分别导入 KaTeX 全局样式，避免纯渲染组件携带入口级副作用。应用启动时解析 URL、localStorage 或宿主传入的主题/语言配置。组件通过 `useI18n` 或 `t` 获取文案。`ConversationMarkdown` 是不依赖 AppContext、鉴权、Desktop Bridge 和具体代码 UI 的消息正文渲染核心，统一负责 GFM、KaTeX 与安全 HTML 配置，并要求入口显式注入代码渲染器；`ReasoningDisclosure` 使用原生 React/CSS Modules，主时间线保留实时状态，分享页以默认折叠方式复用，并在快照提供权威 `durationMs` 时显示“已完成”用时。主对话的 `MarkdownContent` 同步注入完整代码渲染器、鉴权资源、Workspace 链接和 Desktop 操作；匿名分享页只注入安全外链、禁用图片策略和 `ShareMarkdownCode`。后者对行内代码直接渲染，对块级代码按需加载同一个 `ConversationMarkdownCode`，因此保留代码、ECharts 和 Mermaid 能力，同时不把它们放入分享首屏入口包。Mermaid SVG 只允许来自固定 `securityLevel: strict` 配置下的 `mermaid.render` 结果。

## 边界与非目标
- 全局样式新增应先判断是否属于已有 globals 分区。
- 业务组件不应直接复制基础按钮/输入样式。
- 新增用户可见中文时，需要同步 i18n 词条或加入明确允许清单。
- 分享入口不得直接或传递依赖 `app`、`features`、鉴权或 Desktop 数据模块；生产构建后使用 `npm run check:share-bundle` 审计全部分享 chunk 的 source map。
