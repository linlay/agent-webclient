# 样式主题基础UI与国际化

## 当前状态
全局样式入口为 `src/shared/styles/globals.css`，再按 layout、timeline、composer、tools、voice、responsive 等拆分导入。主题工具在 `theme.ts`，基础 UI 组件在 `src/shared/ui/`，国际化运行时在 `src/shared/i18n/`。

## 核心职责
- 统一全局 CSS 入口，避免在 app 入口散落多个全局样式文件。
- 提供主题模式读取、持久化和 document attribute 应用。
- 维护 UiButton、UiInput、UiTag、MaterialIcon、ConversationMarkdown、MarkdownContent 等基础组件。
- 提供 zh-CN/en-US 文案和硬编码中文检查约束。

## 核心流程
`src/app/index.tsx` 导入主应用 `globals.css`。应用启动时解析 URL、localStorage 或宿主传入的主题/语言配置。组件通过 `useI18n` 或 `t` 获取文案。`ConversationMarkdown` 是不依赖 AppContext、鉴权、Desktop Bridge 和具体代码 UI 的消息正文渲染核心，统一负责 GFM、KaTeX 与安全 HTML 配置，并要求入口显式注入代码渲染器；主对话的 `MarkdownContent` 再注入完整代码渲染器、鉴权资源、Workspace 链接和 Desktop 操作。匿名分享页不再重建 transcript 或复用 Markdown 组件，只负责受限 Blob iframe 宿主。

静态 HTML 导出使用独立 CSS Modules、原生 `details/summary`、严格 Snapshot V1 parser 和固定语言集合的同步代码高亮，避免 Ant Design、Context、Router 与业务网络进入文件。模板不再内联 CSS 或可执行 JS：React、ReactDOM、KaTeX 与导出样式进入同一主 JS/CSS，ECharts/Mermaid 仅在命中对应代码块时从主 runtime 所在的内容寻址资产目录各加载一次，失败回退源码。Highlight 与 Mermaid 生成 markup 统一经过唯一 DOMPurify 边界；每轮内容使用 `content-visibility` 优化长对话，打印媒体规则展开思考，明暗色跟随 `prefers-color-scheme`。

## 边界与非目标
- 全局样式新增应先判断是否属于已有 globals 分区。
- 业务组件不应直接复制基础按钮/输入样式。
- 新增用户可见中文时，需要同步 i18n 词条或加入明确允许清单。
- 静态导出组件树不得依赖主应用状态、鉴权、Desktop Bridge 或业务网络；富文本只经过集中式 `SanitizedMarkup`/DOMPurify 边界。
- 导出入口不得包含业务网络、鉴权或 Desktop Bridge；生产构建后使用 `npm run check:conversation-export` 校验模板无内联样式/可执行脚本、唯一 Snapshot 占位符、内容寻址资产、CSP、SRI、固定依赖版本和包体预算。
