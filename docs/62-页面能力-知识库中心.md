# 知识库中心

设置菜单 KBases Center 打开 `/kbases` 独立管理页。`app/pages/kbases` 只装配 `features/kbases`，该 feature 负责列表刷新、编辑表单、任务状态轮询和召回结果。接口定义与鉴权 HTTP 请求由 `shared/data` 提供。

支持新建、查看、名称描述编辑、删除、手动索引更新、已索引文档浏览和全文召回测试。源路径为 Platform 机器上的已有绝对目录，创建后不可更改；删除保留该源目录。首次索引需要点击“更新索引”。后台任务期间每两秒刷新定义列表，任务完成或失败后停止轮询。页面展示最近成功索引时间与错误；失败后仍可查看已有成功索引的数据。

召回显示 KBX 真实片段、来源、行号和相关性分数，返回数量 1–50，空结果独立展示。文档预览为前 200 行，截断时提示。切换知识库或卸载时取消未完成的数据请求，防止旧结果覆盖当前库。

当前为全文召回，未提供向量模型配置、上传、自动监听或 Agent 挂载。Platform 持久化目录为 `AP_RUNTIME_DIR/kbases-center`。管理接口为 `/api/admin/kbases` 及 `/{id}`、`/{id}/refresh`、`/{id}/files`、`/{id}/search`、`/{id}/read`，沿用 HTTP 鉴权与统一 JSON 包裹。
