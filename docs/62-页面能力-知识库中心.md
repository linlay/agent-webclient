# 知识库中心

左侧栏 Quick Actions 的知识库（KBases）按钮与 Agents 同级，点击在当前页面打开知识库对话框（最大宽度 1320px、高度 min(84dvh, 860px)，与 Agents 一致）；Copilot 使用同一命令容器的 Drawer，`/kbases` 仍可作为独立管理页访问；入口受 `QUICK_ACTIONS_ENABLED` 控制，设置菜单不再提供该入口。`app/pages/kbases` 只装配 `features/kbases`，该 feature 负责列表刷新、编辑表单、任务状态轮询和召回结果。接口定义与鉴权 HTTP 请求由 `shared/data` 提供。

支持新建、查看、名称描述编辑、collection 增删及名称/来源修改、删除、手动索引更新、已索引文档浏览和召回测试。创建和编辑均允许 1–32 个 collection，每项包含独立名称与 Platform 机器上的已有绝对源目录。名称与解析后的目录不能重复；移除 collection 或删除知识库都保留源目录。集合范围改变后，Platform 将库标记为 `unindexed` 并清零当前范围的 `indexedAt`，后台自动对账更新，避免展示旧范围的数据。仅修改名称描述或调整 collection 顺序保留索引。旧单目录库以 `workspace` collection 展示，已有索引和引用保持有效。首次索引由后台自动维护，“更新索引”用于手工触发。后台任务期间每两秒刷新定义列表，任务完成或失败后停止轮询。索引期间禁用编辑与删除；同一来源范围的更新失败后仍可查看已有成功索引的数据。

页面沿用 Agents / Skills 管理页的填充式搜索、同排刷新/新建按钮、平铺列表、可拖拽列表宽度和右侧固定工具栏。默认打开 Documents，Collection 是文档筛选维度，支持按集合和文件名/标题联合过滤，点击文档行的集合名也可筛选。选择集合后只显示该集合的单行源目录；不在顶部逐行展开所有来源。Retrieval test 为独立页签，其多选集合范围最多占一行。编辑窗口整体限高并滚动，保留集合数量、名称唯一性和字段校验。

召回默认使用 KBX `query` 综合召回，也可选择全文 `search`、向量相似度 `vsearch` 或图检索 `gsearch`。向量模式要求已配置查询模型且向量索引完整，图检索要求完整图谱；页面根据 `/status` 禁用未就绪方式并解释原因。`query` 使用可用通道，页面展示实际通道和不完整/降级提示。未选择集合时使用库的默认检索集合，也可显式选择多个集合，每条真实 chunk 单独展示 collection、集合内相对文件路径、片段编号、抽取文本行号和向量相似度，返回数量 1–50，结果保持 KBX 的统一相关性排序。文档列表也显示集合与路径。文档预览为前 200 行，截断时提示。切换知识库或卸载时取消未完成的数据请求，防止旧结果覆盖当前库。

模型默认来自 Platform runtime.kbx，可在 library.yml 覆盖 embedding 并配置 reranker、queryExpansion；页面不提供逐库模型编辑。中心已支持自动监听和 Native Agent 绑定，图谱构建和上传仍未接通。Platform 配置目录为 `AP_RUNTIME_DIR/kbases/<id>/library.yml`，索引保存在 `ru-kbases/<id>/`。创建请求使用 `{name,description,collections:[{name,sourcePath}]}`，召回请求使用 `{query,limit,collections?,method?}`，`method` 缺省为 `query`。管理接口为 `/api/admin/kbases` 及 `/{id}`、`/{id}/refresh`、`/{id}/status`、`/{id}/files`、`/{id}/search`、`/{id}/read`，沿用 HTTP 鉴权与统一 JSON 包裹。

召回结果的 `score` 为原始查询与 chunk 的向量相似度，`scoreType: vector_similarity` 才显示数值（保留四位小数）；`score: null`、`scoreType: unavailable` 或旧后端缺少类型时显示 `—`，不使用排名分、全文分或图分作为替代。结果顺序保持后端融合排序；`rankingScore` 仅保留诊断用途，不作为界面相似度展示。相似度不是答案置信度，界面提示说明此区别。

管理列表中的 `invalidId: true` 条目只展示诊断，禁用编辑、刷新和删除，需在主机上修正目录名。`sourceWarnings` 与 `refreshError` 使用警告展示，与不可用状态的 `error` 分开；来源离线或刷新尚未开始即失败时，仍按 `indexedAt` 决定已完成索引是否可浏览。

集合支持 description 与 editable（缺省 false），管理表单保留 include/exclude/chunk。仅专用 KBASE 的 Host Run 在启动时冻结可编辑目录，需 editingMode 才能写；容器不自动挂载，普通 Agent 不获得额外写权限。说明与开关不触发索引重建，下次 Run 生效。

库级 retrieval（数量、候选预算、最低分、时效权重和可选模型开关）、查询模型与 collection.defaultQuery 由 YAML / 管理 API 配置。召回表单初始数量使用库 topK（缺省 8），用户修改后作为单次覆盖；集合未选择时遵循 defaultQuery（缺省 true），所有集合默认排除时返回空结果，显式选择仍可检索。defaultQuery 不影响文档浏览和编辑权限，编辑表单保存时保留该值；库级高级字段省略，由后端保留。重排与扩展只在相应查询触发，失败保留可用结果并报告降级，目标环境的延迟和检索质量待实测。
